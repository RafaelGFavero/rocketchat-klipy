### Task 1: Message language falls back to the app's own Search language

**Why:** `languageOf()` reads the server setting `Language`. Apps-Engine 1.46 (`ServerSettingBridge.hasReadPermission`) refuses that read because the app does not declare `server-setting.read`, logs a `PermissionDeniedError` on every command, and the catch falls back to English. The fix shipped in 0.1.0 never worked on a real server; the tests passed because the `IRead` mock ignores permissions. Rather than ask for a broad permission, the fallback becomes the app's own `klipy_locale` setting. The default search language becomes `en_US`, since the Marketplace is global.
