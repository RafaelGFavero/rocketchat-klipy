## 1. O que é este App

O **KLIPY GIFs for Rocket.Chat** ("o App") é um aplicativo de terceiros para Rocket.Chat
que adiciona o comando `/klipy` para pesquisar e compartilhar GIFs fornecidos pela API
do KLIPY.

O App é distribuído **gratuitamente**, sob a [licença MIT](LICENSE), por **RF Tecnologia**
("nós").

Este é um projeto independente. **Não somos afiliados, endossados ou patrocinados pelo
KLIPY nem pelo Rocket.Chat.**

## 2. O que o App faz — e o que não faz

O App é um **cliente**. Ele traduz o comando `/klipy` em chamadas à API do KLIPY, feitas
pelo servidor Rocket.Chat do seu próprio workspace, e publica na sala o GIF que você
escolher.

Não existe servidor, proxy ou banco de dados operado por nós em nenhum ponto do fluxo.
Não recebemos, armazenamos nem processamos qualquer dado seu. Ver [PRIVACY.md](PRIVACY.md).

## 4. O conteúdo é do KLIPY

Todos os GIFs são fornecidos pelo KLIPY. Não hospedamos, produzimos, selecionamos,
moderamos nem endossamos esse conteúdo — o App apenas exibe o que a API devolve, na
ordem em que ela devolve.

Se você encontrar conteúdo impróprio:

- ajuste o **filtro de conteúdo** nas configurações do App (`off`, `low`, `medium`, `high`);
- configure bloqueios de termos ou palavras no Partner Panel do KLIPY;
- reporte ao KLIPY em support@klipy.com.

Cabe ao administrador do workspace definir o nível de filtro adequado ao seu público.
